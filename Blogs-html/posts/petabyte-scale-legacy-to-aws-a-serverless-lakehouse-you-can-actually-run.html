Land decades of history + CDC from Oracle/SQL Server/etc. into S3, secure it with tags & LF-tags, query with Athena/Iceberg, add full-text search, and train ML — all serverlessly and cost-optimized.

Reading time: 12–15 mins Audience: Senior/Principal Data & ML Architects, Platform Engineering, FinOps

This blueprint shows how to migrate petabyte-scale historical + CDC data from common legacy databases into an AWS serverless lakehouse on Amazon S3. You’ll use object tags and Lake Formation LF-tags for governance and automated lifecycle (Intelligent-Tiering/Glacier), Athena + Iceberg for ACID/time-travel queries, OpenSearch Serverless for free-text search, and Step Functions + SageMaker to train ML on ephemeral compute. Code samples include CDK (TypeScript), PySpark (Glue), SQL (Athena), Lambda (Node.js), and SageMaker SDK (Python).
