🚢 Why We’re Talking About This

If you’ve ever shipped something that cannot get too warm, too cold, too bumpy, too humid, or too shaken… you know the anxiety.

  • Pharmaceuticals that lose potency if they warm up for 30 minutes
  • Fine art that can’t handle a degree of tilt without losing value
  • Exotic food that must stay at -18°C from producer to plate
  • Electronics that fail under excessive vibration
  • Chemicals that become unstable at certain temperatures

The old way?
Put a cheap logger in the crate, read it after arrival, and hope nothing went wrong.

The new way?
Build a real-time global monitoring system that tells you instantly when conditions go bad — and lets you do something about it.

Today, we’ll walk through a hardware + software stack using:

  • AWS native services for ingestion, storage, analytics, and alerts
  • Starlink for always-on connectivity at sea, in the air, or on the road
  • Off-the-shelf IoT devices (no need to custom-build hardware)
  • ERP/CRM integrations for operational automation
  • Public AWS Solutions to speed up deployment

And yes — we’ll make it fun along the way.

☁ AWS Services Deep Dive

This design is 100% AWS-native — which means you get:

  • No server maintenance
  • Pay-as-you-go pricing
  • Scalability from 10 shipments to 10,000
  • Built-in security and compliance

1. AWS IoT Core

  • Device Registry: Manage device identities and metadata
  • Device Shadow: Maintain last known state even when offline
  • MQTT Broker: Handle millions of concurrent connections
  • Security: X.509 certificates, policies, and encryption
  • Cost: $0.08 per million messages + $0.30 per device/month

2. AWS IoT Rules Engine

  • SQL-like Rules: Route messages based on content
  • Multiple Actions: Send to Kinesis, Lambda, S3, etc.
  • Error Handling: Dead letter queues for failed processing
  • Example Rule:
SELECT 
    temperature_c, 
    humidity_percent, 
    vibration_g, 
    timestamp, 
    device_id 
FROM 'cargo/+/telemetry' 
WHERE temperature_c > 8 OR vibration_g > 2.5

3. Amazon Kinesis Data Streams

  • Real-time Processing: Handle thousands of records per second
  • Multiple Consumers: Lambda, EC2, ECS, or custom applications
  • Retention: 24 hours to 365 days
  • Cost: $0.014 per shard hour + $0.014 per million records

4. Amazon Timestream

  • Purpose-built: Optimized for time-series data
  • Auto-scaling: Automatically adjusts to workload
  • Query Performance: Sub-second query response
  • Cost: $0.50 per GB-month for standard storage

5. Amazon S3

  • Data Lake: Store raw and processed telemetry
  • Lifecycle Policies: Move to Glacier for cost optimization
  • Athena Integration: Query with SQL
  • Cost: $0.023 per GB-month (Standard)

6. AWS Glue + Athena

  • Data Catalog: Discover and organize data
  • SQL Queries: Analyze historical shipment data
  • Serverless: Pay only for queries executed
  • Cost: $5 per DPU-hour (Glue) + $5 per TB scanned (Athena)

7. AWS Lambda

  • Serverless Compute: Scale automatically
  • Event-driven: Triggered by IoT rules or Kinesis
  • Multiple Runtimes: Python, Node.js, Java, Go
  • Cost: $0.20 per 1M requests + $0.0000166667 per GB-second

8. Amazon SNS

  • Multi-channel: SMS, email, push, HTTP/HTTPS
  • Fan-out: Send to multiple subscribers
  • Filtering: Route messages based on attributes
  • Cost: $0.50 per million publishes + delivery costs

9. Amazon Location Service

  • Built-in Maps: No third-party dependencies
  • Geofencing: Real-time location-based alerts
  • Routing: Calculate optimal paths
  • Cost: $0.40 per 1,000 geofence evaluations

10. AWS AppFlow

  • Pre-built Connectors: Salesforce, SAP, NetSuite, etc.
  • Bidirectional Sync: Real-time data flow
  • Scheduled Sync: Batch processing options
  • Cost: $0.001 per record processed

Example Lambda Function for Temperature Alerting:

import boto3
import json
import time
from datetime import datetime, timedelta

# Initialize AWS clients
sns = boto3.client('sns')
timestream = boto3.client('timestream-query')
dynamodb = boto3.client('dynamodb')

def lambda_handler(event, context):
    """
    Process IoT telemetry and trigger alerts for temperature violations
    """
    for record in event['Records']:
        payload = json.loads(record['body'])
        
        # Extract sensor data
        device_id = payload.get('device_id')
        temperature_c = payload.get('temperature_c')
        humidity_percent = payload.get('humidity_percent')
        vibration_g = payload.get('vibration_g')
        timestamp = payload.get('timestamp')
        shipment_id = payload.get('shipment_id')
        
        # Check temperature thresholds
        if temperature_c > 8:
            # High temperature alert
            send_alert(
                alert_type="HIGH_TEMPERATURE",
                severity="CRITICAL",
                device_id=device_id,
                shipment_id=shipment_id,
                value=temperature_c,
                threshold=8,
                message=f"Shipment {shipment_id} temperature {temperature_c}°C exceeds 8°C threshold"
            )
            
            # Check for sustained violation
            check_sustained_violation(device_id, temperature_c, timestamp)
        
        # Check humidity thresholds
        if humidity_percent > 80:
            send_alert(
                alert_type="HIGH_HUMIDITY",
                severity="WARNING",
                device_id=device_id,
                shipment_id=shipment_id,
                value=humidity_percent,
                threshold=80,
                message=f"Shipment {shipment_id} humidity {humidity_percent}% exceeds 80% threshold"
            )
        
        # Check vibration thresholds
        if vibration_g > 2.5:
            send_alert(
                alert_type="HIGH_VIBRATION",
                severity="WARNING",
                device_id=device_id,
                shipment_id=shipment_id,
                value=vibration_g,
                threshold=2.5,
                message=f"Shipment {shipment_id} vibration {vibration_g}g exceeds 2.5g threshold"
            )
        
        # Store in DynamoDB for quick access
        store_telemetry(device_id, payload)
        
        # Update shipment status
        update_shipment_status(shipment_id, payload)

def send_alert(alert_type, severity, device_id, shipment_id, value, threshold, message):
    """Send alert via SNS"""
    alert_payload = {
        'alert_type': alert_type,
        'severity': severity,
        'device_id': device_id,
        'shipment_id': shipment_id,
        'value': value,
        'threshold': threshold,
        'message': message,
        'timestamp': datetime.utcnow().isoformat()
    }
    
    sns.publish(
        TopicArn='arn:aws:sns:us-east-1:123456789012:CargoAlerts',
        Message=json.dumps(alert_payload),
        Subject=f"{severity}: {alert_type} Alert for Shipment {shipment_id}"
    )

def check_sustained_violation(device_id, current_temp, timestamp):
    """Check if temperature violation is sustained"""
    # Query Timestream for recent temperature readings
    query = f"""
    SELECT temperature_c, time
    FROM "cargo_telemetry"."device_readings"
    WHERE device_id = '{device_id}'
    AND time > ago(30m)
    ORDER BY time DESC
    """
    
    try:
        result = timestream.query(QueryString=query)
        
        # Count violations in last 30 minutes
        violation_count = sum(1 for row in result['Rows'] 
                            if float(row['Data'][0]['ScalarValue']) > 8)
        
        if violation_count >= 10:  # Sustained for 10+ readings
            send_alert(
                alert_type="SUSTAINED_TEMPERATURE_VIOLATION",
                severity="CRITICAL",
                device_id=device_id,
                shipment_id=shipment_id,
                value=current_temp,
                threshold=8,
                message=f"Sustained temperature violation for device {device_id}"
            )
    except Exception as e:
        print(f"Error checking sustained violation: {e}")

def store_telemetry(device_id, payload):
    """Store latest telemetry in DynamoDB for quick access"""
    try:
        dynamodb.put_item(
            TableName='cargo_telemetry_latest',
            Item={
                'device_id': {'S': device_id},
                'timestamp': {'S': payload.get('timestamp')},
                'temperature_c': {'N': str(payload.get('temperature_c', 0))},
                'humidity_percent': {'N': str(payload.get('humidity_percent', 0))},
                'vibration_g': {'N': str(payload.get('vibration_g', 0))},
                'location': {'S': json.dumps(payload.get('location', {}))}
            }
        )
    except Exception as e:
        print(f"Error storing telemetry: {e}")

def update_shipment_status(shipment_id, payload):
    """Update shipment status in DynamoDB"""
    try:
        # Calculate overall health score
        health_score = calculate_health_score(payload)
        
        dynamodb.update_item(
            TableName='shipments',
            Key={'shipment_id': {'S': shipment_id}},
            UpdateExpression='SET last_update = :ts, health_score = :hs, current_location = :loc',
            ExpressionAttributeValues={
                ':ts': {'S': payload.get('timestamp')},
                ':hs': {'N': str(health_score)},
                ':loc': {'S': json.dumps(payload.get('location', {}))}
            }
        )
    except Exception as e:
        print(f"Error updating shipment status: {e}")

def calculate_health_score(payload):
    """Calculate overall shipment health score (0-100)"""
    score = 100
    
    # Temperature penalty
    temp = payload.get('temperature_c', 20)
    if temp > 8:
        score -= min(30, (temp - 8) * 5)
    
    # Humidity penalty
    humidity = payload.get('humidity_percent', 50)
    if humidity > 80:
        score -= min(20, (humidity - 80) * 0.5)
    
    # Vibration penalty
    vibration = payload.get('vibration_g', 0)
    if vibration > 2.5:
        score -= min(25, (vibration - 2.5) * 10)
    
    return max(0, score)

Cost Optimization Strategies:

Data Retention Policies

  • Hot data (7 days): Timestream

Message Frequency Optimization

  • Normal conditions: 1 msg/5 minutes

  • Critical conditions: 1 msg/30 seconds

Edge Processing

  • Local aggregation reduces message count
  • Send only significant changes
  • Compress data before transmission

Reserved Capacity

  • 1-year or 3-year commitments

  • Predictable monthly costs
